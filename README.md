# HR Analytics Dashboard – Excel

## 📊 Project Overview

The HR Analytics Dashboard is an Excel-based data analytics project designed to analyze employee demographics, salary, performance, overtime, attrition, and department-level workforce distribution.

The project transforms raw HR employee data into a clean analytical dataset, creates PivotTables and PivotCharts, and presents the results through an interactive dashboard with KPI cards and slicers.

## 🎯 Project Objectives

- Analyze the overall employee workforce.
- Compare male and female employee counts.
- Understand average salary across departments.
- Analyze employee performance ratings.
- Study employee distribution by age group.
- Compare overtime and attrition patterns.
- Analyze department-wise employee distribution.
- Provide an interactive dashboard for HR decision-making.

| Sheet | Description |

## 🧹 Data Preparation

The Clean_data sheet contains the original HR attributes along with additional calculated fields used for analysis.

### Calculated Columns

- Age Group – Groups employees into age ranges such as 20–29, 30–39, 40–49 and 50+.
- Salary Band – Categorizes employees based on salary level.
- Experience Group – Groups employees based on years of experience.

These calculated fields make the dataset easier to analyze using PivotTables and charts.
